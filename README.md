# Scene Branch HUD

Stage 1: проверка загрузки расширения.

## Установка
1. Скопируйте папку в `data/default-user/extensions/scene-branch-hud`
2. Обновите SillyTavern
3. Откройте Extensions → правая панель

## Проверка
- Должен появиться drawer "Scene Branch HUD"
- В консоли (F12) — сообщение `[scene-branch-hud] ✅ Loaded successfully`
- Внутри — заглушка HUD# Scene-Branch-HUD
